# ADR-0006. 품목 행에는 남은 수량만 두고, 잡아 둔 수량과 확정 수량은 구매 품목에서 센다

- 상태: 채택

## 맥락

수량 불변식(판매 수량 = 남은 + 잡아 둔 + 확정)을 테스트마다 검사한다. 몰림 상황에서 수량 갱신은 경합이 모이는 곳이고, C에서 기준선을 재고 개선한다.

## 결정

`item_stock`에는 `remaining`만 둔다. 잡기는 `remaining >= n` 조건부 갱신, 반환은 구매를 잡아 둠에서 실패로 바꾸는 데 성공한 트랜잭션만 더한다. 잡아 둔 수량과 확정 수량은 구매 상태별 구매 품목 합계로 센다.

## 고르지 않은 대안

- 품목 행에 남은·잡아 둔·확정 세 숫자: 한 행에서 불변식을 볼 수 있지만, 같은 갱신이 함께 바꾸는 숫자끼리의 검사라 의미가 작다. 확정 때도 경합 행을 갱신한다.
- 수량 1개당 행(`SKIP LOCKED`로 집기): 경합을 나누지만 기준선으로는 복잡하다. C의 개선 후보로 둔다.

## 결과

- 불변식이 따로 기록된 두 곳(`remaining`, 구매 품목)을 맞춰 보는 검사가 된다.
- 경합 행의 갱신은 잡기와 반환뿐이다. 이 행이 C 기준선의 병목 후보다.
- 여러 품목에서도 품목마다 행 하나다. 여러 품목을 잡을 때는 품목 ID 순서로 잡는다.
