# ADR-0003. 결제사 호출은 DB 트랜잭션 밖에서 하고 전후 상태를 따로 기록한다

- 상태: 채택

## 맥락

결제사는 늦게 답하거나 답하지 않을 수 있다(P7). 결제사가 승인한 결제는 우리 쪽에 기록이 남아 있어야 나중에 찾아 확정하거나 취소할 수 있다(결제 불변식, P8).

## 결정

결제 시도를 "결과 대기"으로 기록하는 트랜잭션을 먼저 커밋하고, 트랜잭션 밖에서 결제사를 호출한 뒤, 결과를 새 트랜잭션에서 조건부 갱신으로 반영한다. 결제사에 보낼 주문 번호와 멱등키는 첫 트랜잭션에서 정해 기록한다.

## 고르지 않은 대안

- 하나의 트랜잭션 안에서 호출: 단순하지만, 결제사가 승인한 뒤 트랜잭션이 롤백되면 결제 기록이 사라져 취소할 단서가 없다. 응답을 기다리는 동안 DB 커넥션도 붙잡는다.

## 결과

- 응답 없음이나 앱 중단에도 "결과 대기" 기록이 남아 재처리가 결제사에 조회할 수 있다.
- 결제 상태에 "결과 대기"이 생기고, 결과 반영은 그 상태를 조건으로 하는 갱신이 된다.
- 결제사 응답을 기다리는 동안 DB 커넥션을 쓰지 않는다.
